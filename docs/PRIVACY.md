# Privacy Policy

Effective date: 2026-08-01

Giant Salamander Skillbox is a skills-only plugin distributed by gestimation.
The plugin does not operate a developer-controlled server, require a user
account, collect telemetry, or transmit user content to gestimation.

The plugin processes material within the host environment selected by the
user. Some workflows may ask the host product to consult public external
sources, such as PubMed, when the user requests external citation verification.
Those requests are performed by the host environment and are subject to the
host provider's and external source's privacy terms.

The plugin does not intentionally store personal data. Users should avoid
providing confidential, personally identifiable, or regulated data unless their
host environment and organizational policy permit it.

Questions may be submitted through the repository's
[issue tracker](https://github.com/gestimation/giant-salamander-skillbox/issues).
