# Support

Support is available in English and Japanese.

Questions, installation problems, and reproducible bug reports are accepted in
the [GitHub issue tracker](https://github.com/gestimation/giant-salamander-skillbox/issues).

Include the following information when possible:

- host product and version: ChatGPT, Codex, or Claude Code
- plugin version
- operating system
- skill name
- prompt or minimal reproduction with confidential information removed
- complete error message

Security-sensitive reports, privacy questions, confidential information, and
secrets should not be posted in a public issue. Send those inquiries to
[gestimation@gmail.com](mailto:gestimation@gmail.com).
